# Gerador de Apresentação – Grupo Rafael Thomaz

Gerador de propostas comerciais personalizadas para o **Grupo Rafael Thomaz / RT Contábil**.

## Como usar

1. Abra o arquivo `gerador-apresentacao-grupo-rafael-thomaz.html` diretamente no navegador (Chrome recomendado).
2. Preencha os campos no painel superior:
   - **Setor / perfil** – escolha o segmento do cliente
   - **Empresa(s)** – uma por linha, até 4
   - **Nome(s) na capa** – nome do contato/responsável
   - **Nome na frase final** – nome para personalizar a chamada de ação
   - **CNPJs com mais de 5 anos** – marque se aplicável
3. Clique em **"Salvar como PDF"** para exportar.

## Exportação como PDF

- Use **Google Chrome** para garantir o layout correto.
- Vá em **Imprimir → Salvar como PDF**.
- Configure: **Sem margens**, **Incluir gráficos de fundo**.
- O tamanho de página 1920×1080 px já está configurado automaticamente.

## Funcionalidades

- ✅ Slides 16:9 (1920×1080 px)
- ✅ Layout personalizado por setor
- ✅ Exportação PDF com layout correto
- ✅ Link WhatsApp clicável com ícone na slide final
- ✅ Personalização de textos por setor (salvo localmente)

## Publicação

Este projeto é uma página HTML única (sem dependências externas de build). Pode ser publicado diretamente via **GitHub Pages**:

1. No repositório GitHub, vá em **Settings → Pages**.
2. Selecione a branch `main` e a pasta `/ (root)`.
3. Salve — a página ficará disponível em `https://<usuario>.github.io/<repositorio>/`.
